# 與宋元思書・山水謎境

國中九年級國文《與宋元思書》文言文學習 3D RPG。學生乘烏篷扁舟順流而下（從流飄蕩，任意東西），穿行富陽到桐廬的百里江峽，沿途尋訪立於江心礁石、刻著關鍵字的「字碑」，闖過四關水月江門後看到結算成績。

純網頁版，不需要安裝任何東西、不需要網路、離線也能玩。支援**電腦桌機**與**平板電腦（觸控操控）**。

## 怎麼玩

### 給學生：直接開網址

**<https://chuyk.github.io/wenyan-rpg/>**

Chrome / Edge / Safari 開啟就能玩，支援電腦與平板操作（手機螢幕較小，進入前會提示建議以電腦或平板遊玩）。
第一次點進畫面後，音樂才會開始播（瀏覽器的自動播放限制）。

### 給老師：離線版本（教室沒網路時）

```bash
git clone https://github.com/chuyk/wenyan-rpg.git
cd wenyan-rpg
./play.sh          # 預設 8000 埠
```

然後在 Chrome / Edge 打開 `http://localhost:8000`。其他埠：`./play.sh 9000`

> ⚠️ 必須用上面這個方式開啟。**不要直接雙擊 `index.html`** —— 瀏覽器會因為
> ES 模組的同源限制拒絕載入，畫面會是全白。瀏覽器網址列打 `file://` 也是一樣的問題。

### 裝置與操作方式

本遊戲支援**電腦桌機（鍵盤滑鼠）**與**平板電腦（觸控操控）**：

#### 1. 電腦桌機（鍵盤滑鼠）
| 按鍵 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向鍵 | 划船前進／後退／左右操舵 |
| 滑鼠移動 | 轉向與環顧山水（點一下畫面鎖定游標） |
| `Shift` / `空白鍵` | 奮楫加速（順流疾行） |
| `Esc` | 放開滑鼠／暫停遊戲 |
| `1` `2` `3` `4` | 答題時直接選第 n 個選項 |
| `Enter` | 答題後繼續 |
| `M` | 音樂靜音／恢復 |
| `−` `=` | 音量 −10%／+10% |

#### 2. 平板電腦（觸控操控）
| 觸控區域 | 功能 |
| --- | --- |
| 左下角虛擬搖桿 | 划船行舟、轉向與左右偏航 |
| 畫面右側滑動 | 單指滑動平滑環顧兩岸山水 |
| 右下角「奮楫」按鈕 | 按住加速航行（等同 Shift） |
| 右上角「⏸」按鈕 | 隨時開啟暫停選單（調音量、切換畫質、查看操作） |
| 題目選項按鈕 | 手指直接點選答案 |

> 📱 **手機螢幕提醒**：由於手機螢幕較小，閱讀字碑題目與欣賞兩岸山水視野有限，遊戲在開始前會跳出溫馨提示，建議以電腦或平板橫向遊玩（使用者亦可選擇確認後繼續體驗）。

### 玩法規則

- **江行尋碑**：每關沿江有三面**江中字碑**，乘舟靠近就會觸發文言解題（實詞／虛詞／翻譯／通假字）。
- **答題獎懲**：答對 → 字碑碎裂消失，`+100` 分。答錯 → `−25` 分、扣 1 顆心，並顯示正解與講解。
- **同一面字碑再答錯不再扣心**，但第一次就答對與否會影響最後的「答題正確率」。
- **水月江門**：三面字碑全破 → 前方紅色水幕化為金色光華，乘船穿過水門進入下一關。
- **過關結算**：每關全對有 `+50` 完美獎金。心歸零則結束。結算依第一次答對率給予「妙筆生花」、「胸有成山水」等文雅評價。
- **本機存檔與無縫接續**：
  - 進度會即時自動保存在瀏覽器的 `localStorage`（記錄當前關卡、累積分數、生命數與答題統計）。
  - 無論在中途返回標題畫面或關閉瀏覽器，標題畫面均會顯示醒目的**「📜 本機存檔進度」**資訊卡與金光呼吸效果的**「繼續航程（第 N 關）」**按鈕，點擊即可無縫接續！
  - 玩家亦可選擇「開始全新旅程（從第一關）」或點選「清除存檔」重置紀錄。

### 遊戲感與江行機制

- 💥 **暗礁險灘碰撞懲罰（「泉水激石，泠泠作響」）**：
  - 江面上分布有突出的青黛暗礁與激流險石（小地圖以褐紅圓點標示）。
  - 若木舟不慎觸礁，將觸發**木身碰撞震顫音效、水花飛濺、畫面微震與紅暈受損視覺**，並**扣除 15 分**。
  - 連續觸礁每達 3 次將額外損耗 1 點生命，並具備 1.5 秒無敵回彈保護，考驗玩家在富春江上的操舵技巧！
- 🌊 **急流衝浪推進帶（「急湍甚箭，猛浪若奔」）**：
  - 第二關特別設有青藍色翻騰浪花帶（小地圖以青藍色長條標示）。
  - 駛入急流帶可獲得 **+60% 破浪加速推進** 與 **+10 順流加分**！
- ⛵ **平穩行舟獎勵（「從流飄蕩，平穩如鏡」）**：
  - 若能連續 22 秒保持航行且未觸碰暗礁，即可獲得 **+20 雅興分**！
- 🎣 **沿江生態與 NPC 互動**：
  - 富春江釣叟（簑衣老翁）、宋府信鴿（江心石樁）、經綸世務者（窺谷忘反官員）、百叫靈猿、游魚躍水、發光漂流竹筒等趣味彩蛋。

### 為什麼要自己寫音訊迴圈

原始錄音有很強的場地殘響（動態範圍只有約 10 dB），樂句之間沒有真正的靜默，
直接 `loop` 會在接縫處聽到明顯斷點。所以 `src/audio.js` 在播放時做 **3.5 秒等功率交叉淡化**，
把尾端淡出和開頭淡入疊在一起，接縫就聽不出來了。音檔本身不必事前處理。

### 換成自己的音樂

把檔案丟進 `audio/music/`，改 `src/audio.js` 的 `TRACKS` 即可：

```js
const TRACKS = {
  menu: { file: "my-music.mp3", title: "曲目名", credit: "演奏者" },
  1: { file: "my-music.mp3", title: "曲目名", credit: "演奏者" },
  // 2 / 3 / 4 依此類推
};
```

支援 mp3、ogg、wav、m4a。單一檔案解碼後約佔 480 欄 × 長度 × 4 bytes 的記憶體，
曲子超過 4 分鐘在舊電腦上會有點吃力，建議先裁到 2 分鐘內。

四關依《與宋元思書》原文行文推進，每關前有一張導讀卡。

| 關 | 主題 | 原文 | 字碑 |
| --- | --- | --- | --- |
| 一 | 風煙俱淨 | 風煙俱淨，天山共色。 | 淨、俱、從 |
| 二 | 奇山異水 | 自富陽至桐廬一百許里，奇山異水，天下獨絕。 | 許、絕、東 |
| 三 | 水皆縹碧 | 水皆縹碧，千丈見底。急湍甚箭，猛浪若奔。 | 縹、疾、奔 |

共 12 題，含實詞解釋、虛詞辨析、句子翻譯與通假字（反通返），每題都附講解。

## 老師可以改什麼

所有題目、原文、導讀文都在 **`src/data.js`** 一個檔案裡，改完存檔、重新整理瀏覽器即可生效，不用重新安裝任何東西。

### 加一道題

在對應關卡的 `steles` 陣列裡加一個物件：

```js
{
  char: "絕",                    // 刻在字碑上的字
  tag: "實詞",                   // 顯示在題目旁的分類標籤
  hint: "「絕」有斷絕和好到極點兩種意思。",
  question: "「天下獨絕」的「絕」意思是？",
  options: [
    opt("絕妙、獨一無二", true, "這裡指山水好到極點，天底下找不出第二處。"),
    opt("斷絕、斷掉"),
    opt("絕望、走投無路"),
  ],
}
```

- `correct: true` 的選項必須**有且只有一個**。
- `note` 是答對後（或答錯時）顯示的講解。
- 選項順序每題都會自動洗牌，所以不用自己打亂。

### 改字碑數量

`steles` 陣列放幾個就是幾面字碑。放 4 個以上也可以，位置會自動平均分布。

### 改關卡外觀

每關的 `theme` 物件控制顏色：

```js
theme: {
  sky: [0x6e93b4, 0xc9d2c4],   // 天頂色、接近地平線的顏色（十六進位）
  fog: 0xa8b8b4,                // 霧色
  sun: 0xffe2a8,                // 陽光色
  ground: 0x4e6b3c,             // 山坡草色
  water: 0x4d8496,              // 河水色
  tree: 0x1f3a22,               // 樹冠色
  height: 66,                   // 山有多高（數字越大越壯觀）
  riverWidth: 28,               // 江面寬度
  birds: 6,                     // 天上盤旋的鳶數量
}
```

想快速改的話，直接複製某一關的 `theme` 過來改最快。

### 改評價標準

檔案最下面：

```js
export const RESULT_RANKS = [
  { min: 92, label: "妙筆生花", note: "你已讀懂《與宋元思書》的山水與心境。" },
  ...
];
```

`min` 是答對率門檻，`label` 是顯示的評等，`note` 是給學生的一句話。

### 改計分

在 `src/main.js` 最上方：

```js
const MAX_LIVES = 6;          // 幾顆心
const STELE_SCORE = 100;      // 破一面字碑
const LEVEL_CLEAR_SCORE = 100;// 通關
const PERFECT_BONUS = 50;     // 整關零失誤
const WRONG_PENALTY = 25;     // 答錯扣分
```

```
├── LICENSE             MIT
├── .nojekyll           讓 GitHub Pages 原樣發佈、不經過 Jekyll
├── src/
│   ├── style.css       水墨風介面樣式
│   ├── data.js         ★ 題庫、原文、關卡設定（老師主要改這個）
│   ├── main.js         遊戲主流程：關卡切換、計分、存檔、結算
│   ├── world.js        3D 世界：地形、河水、森林、遠山、字碑、山門
│   ├── player.js       第一人稱移動與碰撞
│   ├── quiz.js         解題對話框
│   ├── audio.js        BGM：解碼、等功率循環淡化、關卡切換、靜音與音量
│   ├── quality.js      畫質自動偵測（軟體光柵化 → 低畫質）與手動切換
│   └── hud.js          HUD、小地圖、導讀卡、結算畫面
├── audio/
│   ├── CREDITS.md      音樂來源、授權、做過的處理
│   └── music/          5 個 mp3
└── vendor/
    ├── README.md         第三方程式碼說明與升級方式
    ├── three.module.js   Three.js r180
    └── three.core.js     （離線使用，不需連網）
```

`vendor/` 是**刻意提交**的：這個專案要能離線跑、不用 CDN、沒有 npm 與打包步驟，
`index.html` 直接用 import map 指向它。詳見 [`vendor/README.md`](vendor/README.md)。

第三方授權：Three.js 為 MIT（聲明內嵌於檔頭）；古琴錄音為 CC BY 2.5，
完整署名見 [`audio/CREDITS.md`](audio/CREDITS.md) 與遊戲內「音樂與版權」頁面。

地形、樹林、遠山都是**程式即時生成**的，沒有任何模型或圖片檔案。
連音樂一共約 5 MB，其中 2 MB 是 Three.js、3 MB 是音樂。

## 課堂運用建議

- **投影**：老師開自己的瀏覽器到上面的網址，讓全班看著解題。
- **分組競賽**：把學生分成幾組，各用一台電腦開同一個網址，結算畫面的分數直接比較。
- **成績回報**：結算畫面會顯示每關破的字碑與用時，可直接截圖或抄下來。不過成績目前只存在各學生的瀏覽器裡，**沒有自動上傳**；若要全班成績彙整，可以再開一支小工具把分數送到試算表，告訴我再幫你加。
- **延伸**：把 `data.js` 的關卡複製品做成《答謝中書書》《三峽》，就是同一個遊戲的第二、三課。
- **配合朗誦**：第三關的「流水」正好是課文「急湍甚箭，猛浪若奔」的音樂化表現，可以讓學生先聽曲再讀句子。

## 已知的限制

- 只針對**桌機瀏覽器**（需要滑鼠鎖定與獨立顯示卡）。手機與平板沒有適配觸控操作。
- 需要支援 WebGL 2 的瀏覽器（Chrome、Edge、Firefox、Safari 近年版本都可以）。
- 沒有音效（只有背景音樂），也沒有配樂跟著關卡情緒變化以外的動態調整。
- 成績只存在各學生的瀏覽器裡，換電腦或清除網站資料就會消失。
- 不呼叫任何模型 API 或外部服務，全部題庫寫死在 `data.js`，所以離線也能玩、也不會外傳學生作答。
